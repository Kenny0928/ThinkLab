# 小學程式基礎學習地圖：第一階段

適用對象：小學中年級、小學高年級，以零基礎或初學者為主  
建議工具：Scratch／Blockly；高年級可同步對照 Python  
本階段目標：建立「讀懂任務 → 拆成步驟 → 儲存資料 → 做判斷 → 重複處理 → 驗證結果」的基本思考習慣

> 這是一張涵蓋 15 個概念的學習地圖，編號已全部重排為連續整數 1–15；新增的「文字還是數字」（5）、「整除與餘數」（7）、「小數與格式化輸出」（8）、「布林值與 and／or／not」（11）依先備關係插入既有順序中，不再需要用 8.5 這種小數編號。不建議在一堂 45～90 分鐘的課中全部教完：若「今天」是完整工作坊，可分成五節；若是一般單節課，建議教到概念 3 或 4，並以通關狀況決定進度。

## 一、教學設計原則

每個概念都使用相同節奏：

1. **我做你看**：老師講解並示範例題。
2. **我們一起做**：學生先用嘴巴或追蹤表預測結果，再共同完成。
3. **你做我看**：學生完成核心變體 A。
4. **挑戰延伸**：已完成的學生做變體 B；不把速度當作能力高低。
5. **出口問題**：學生不用看程式，也能說出「輸入是什麼、程式做了什麼、輸出是什麼」。

### 同班分流方式

- **小學中年級核心線**：先完成每個概念的教師例題與變體 A；輸入數量小、可以手算，以積木為主。
- **小學高年級核心線**：完成變體 A、B；開始閱讀簡短 Python，但不強迫第一次就能獨立打字。
- **超前學生**：不提早塞進新語法，而是請他解釋、找反例、設計測試資料或當小老師。
- **需要支持的學生**：提供已排好的積木，只留 1～2 個空格讓他選擇；先口頭說出結果，再操作電腦。

### 自動判分共同規則

- 題目都設計成文字輸入／文字輸出，因此未來可放進 ThinkLab。
- 學生不應輸出「請輸入數字」之類提示文字；只輸出題目要求的答案。
- Scratch／Blockly 課堂可用「詢問並等待」接收輸入、「說出」呈現答案；轉入 Judge 時對應 `input()` 與 `print()`。
- 中文文字、大小寫、空格與換行都要照題目規定，藉此建立精確表達習慣。
- 高年級第一次接觸 Python 輸入時，先提供 `n = int(input())` 骨架，讓學生專注於「取得數字」；不要在同一刻要求他完整理解函式呼叫、文字轉數字與括號語法。

## 三、概念教學卡與題目

### 概念 1：精確輸出

**教學目標**：學生知道程式必須按照指定的文字、大小寫、空格與換行輸出。  
**積木／Python 對照**：「說出」↔ `print()`  
**教師提問**：「如果少一個字、換錯一行，電腦會不會知道我們的意思？」

#### 教師例題：機器人報到

請依序輸出兩行：

```text
我是小幫手
準備完成
```

老師示範重點：一個輸出積木負責一行；文字中的空格也是答案的一部分。

#### 變體 A（中年級核心）：我的第一個程式

不需輸入，輸出：

```text
Hello!
我會寫程式
```

#### 變體 B（高年級追加）：符號小旗子

不需輸入，輸出三行：

```text
***
**
*
```

**常見錯誤**：多輸出提示語、中文驚嘆號和半形 `!` 混用、把多行寫成同一行。  
**通關標準**：能在不試錯超過兩次的情況下得到完全相同的輸出。  
**未來連接**：所有自動判分題、格式化輸出。

---

### 概念 2：指令順序

**教學目標**：學生能由上而下追蹤程式，理解改變順序會改變結果。  
**積木／Python 對照**：上下排列的積木 ↔ 由上而下的程式行。  
**教師提問**：「穿襪子和穿鞋子可以交換順序嗎？哪些指令不能交換？」

#### 教師例題：火箭發射

不需輸入，依序輸出：

```text
3
2
1
出發
```

老師先故意把 `出發` 放在最上面，請學生預測，再共同修正。

#### 變體 A（中年級核心）：交通號誌

不需輸入，依序輸出：

```text
紅燈停
綠燈行
安全到達
```

#### 變體 B（高年級追加）：倒序口令除錯

下面四張指令卡被打亂：`完成`、`步驟 2`、`開始`、`步驟 1`。請排好程式，使輸出為：

```text
開始
步驟 1
步驟 2
完成
```

**常見錯誤**：以為電腦會自行判斷合理順序；只看積木顏色、不從起點逐步追蹤。  
**通關標準**：看到 4～6 條輸出指令時，能在執行前正確寫出結果。  
**未來連接**：變數更新順序、演算法步驟、除錯。

### 概念 3：輸入與回應

**教學目標**：學生分辨輸入與輸出，並能讓程式處理不同使用者提供的資料。  
**積木／Python 對照**：「詢問並等待」與「回答」↔ `input()`。  
**教師提問**：「同一個程式換一個輸入，答案應不應該跟著改變？」

#### 教師例題：回音機器人

輸入一個名字，原樣輸出這個名字。

範例輸入：

```text
小安
```

範例輸出：

```text
小安
```

先用 `小安` 測試，再換成 `樂樂`，證明程式沒有把答案寫死。

#### 變體 A（中年級核心）：喜歡的動物

輸入一種動物，輸出 `我喜歡`、一個半形空格，再輸出動物名稱。

範例輸入：

```text
貓
```

範例輸出：

```text
我喜歡 貓
```

#### 變體 B（高年級追加）：交換播報

依序輸入兩個代號，輸出時交換順序，每個代號一行。

範例輸入：

```text
A7
B3
```

範例輸出：

```text
B3
A7
```

**常見錯誤**：把範例值直接寫進程式、輸出問題提示、混淆兩次輸入的先後。  
**通關標準**：更換至少 3 組輸入後仍能得到正確輸出。  
**未來連接**：變數、測試資料、通用程式。

### 概念 4：變數與更新

**教學目標**：學生把變數理解為有名稱、內容可以改變的盒子，能逐步追蹤目前值。  
**積木／Python 對照**：「將 score 設為」「將 score 改變」↔ `score = ...`、`score = score + ...`。  
**教師提問**：「盒子換了內容後，舊的內容還是現在的答案嗎？」

#### 教師例題：能量補充

輸入目前能量，補充 10 點後輸出新能量。

```text
輸入：35
輸出：45
```

用追蹤表畫出：`能量：35 → 45`。

#### 變體 A（中年級核心）：送出兩顆糖

輸入糖果數量，送出 2 顆後輸出剩餘數量。輸入保證至少是 2。

```text
輸入：9
輸出：7
```

#### 變體 B（高年級追加）：兩次分數更新

輸入原本分數，先增加 8 分，再扣掉 3 分，輸出最後分數。

```text
輸入：20
輸出：25
```

**常見錯誤**：把變數名稱當成畫面文字；第二次更新仍使用最初值；把 `=` 當成數學上的永遠相等。  
**通關標準**：能填完三欄追蹤表「執行前／執行指令／執行後」。  
**未來連接**：計數器、累加器、角色狀態、演算法狀態。

### 概念 5：文字還是數字

**教學目標**：學生能分辨文字與數字兩種資料，知道 `input()` 拿到的一定是文字，要做數學前必須先轉成數字。  
**積木／Python 對照**：Scratch／Blockly 會自動判斷資料型別 ↔ Python 要用 `int()`、`str()` 手動轉換。  
**教師提問**：「同樣寫 `+`，文字的「3」加「5」和數字的 3 加 5，為什麼一個是接起來、一個是相加？」

#### 教師例題：記分板兩種顯示

依序輸入兩個整數 a 和 b。第一行原封不動地把兩個輸入接成一段文字，第二行輸出兩數相加的結果。

```text
輸入：
3
5
輸出：
35
8
```

老師示範重點：`a + b` 在兩個變數都是文字時是「接在一起」；要相加必須先用 `int(a) + int(b)` 轉換成數字。

#### 變體 A（中年級核心）：選手編號

輸入一個整數 n，代表選手編號，輸出格式是「No.」接上編號。

```text
輸入：7
輸出：No.7
```

n 已經用 `int()` 轉成整數，要接文字前得先用 `str(n)` 轉回去。

#### 變體 B（高年級追加）：先轉再算

輸入一行，包含兩個整數，中間用一個空格分開。把這一行拆成兩段文字，各自轉成整數後再相加，輸出加總。

```text
輸入：3 5
輸出：8
```

**常見錯誤**：以為 `input()` 拿到的是數字，直接拿去做數學，出現 TypeError；把 `int()` 套在整個 `input().split()` 上，而不是分別轉換每一個變數。  
**通關標準**：能說出「什麼時候要轉、什麼時候不用轉」，並且看到 TypeError 訊息時能自己找出原因。  
**未來連接**：概念 6 的四則運算、LV.2 的清單讀取。

### 概念 6：算術運算與算式

**教學目標**：學生能把一句生活規則轉成算式，並使用括號表達先後。  
**積木／Python 對照**：四則運算積木 ↔ `+ - *`；中年級先用加減，高年級加上乘法與三數混合運算。  
**教師提問**：「題目給了哪些數？答案是用哪一個規則從它們算出來？」

#### 教師例題：長方形面積

輸入長和寬，輸出面積。

```text
輸入：
6 4
輸出：
24
```

老師畫出長方形，先讓學生說出 `長 × 寬`，再選運算積木。

#### 變體 A（中年級核心）：長方形周長

輸入長和寬，輸出周長。

```text
輸入：
6 4
輸出：
20
```

提醒：可寫成 `(長 + 寬) × 2`；用 `6 + 4 × 2` 可示範括號的重要。

#### 變體 B（高年級追加）：總價計算

輸入單價、數量與運費三個整數（同一行、空白分隔），輸出總金額，計算方式是「單價 × 數量 + 運費」。

```text
輸入：
50 3 20
輸出：
170
```

**常見錯誤**：選錯運算、忽略括號、把周長和面積混淆、忘記先算「單價 × 數量」就把運費也乘了進去。  
**通關標準**：先寫出算式再做積木，並用另一組數字手算驗證。  
**未來連接**：概念 7 的整除與餘數、座標、索引、公式模擬。

### 概念 7：整除與餘數

**教學目標**：學生能用整除回答「可以分成幾份」，用餘數回答「還剩幾個」，並知道 `//` 不是四捨五入。  
**積木／Python 對照**：積木的「除法取整數」「除法取餘數」↔ Python `//`、`%`。  
**教師提問**：「23 顆糖每袋裝 5 顆，可以裝滿幾袋？還剩幾顆？」

#### 教師例題：分裝點心

輸入總數量與每組人數（同一行、空白分隔），第一行輸出可以分成幾組，第二行輸出還剩下幾個。

```text
輸入：23 5
輸出：
4
3
```

老師示範重點：`//` 只留整數部分、不四捨五入；`%` 是分完後剩下的量；想知道能不能整除，就看 `%` 是不是 0。

#### 變體 A（中年級核心）：秒數換算

輸入總秒數，換算成分與秒，輸出「X 分 Y 秒」。

```text
輸入：125
輸出：2 分 5 秒
```

#### 變體 B（高年級追加）：拆出個位與十位

輸入一個 0 到 99 之間的整數，第一行輸出十位數字，第二行輸出個位數字。

```text
輸入：47
輸出：
4
7
```

**常見錯誤**：用 `/` 得到小數（`23 / 5` 是 `4.6` 不是 `4`）；把 `//` 和 `%` 的結果順序寫反，導致組數和剩餘數對調。  
**通關標準**：能在不看程式的情況下，口頭算出任意兩個正整數的 `//` 與 `%` 結果。  
**未來連接**：LV.2 的數字拆解與進位轉換、概念 8 的小數格式化對照。

### 概念 8：小數與格式化輸出 🐍 Python 限定

**教學目標**：學生能分清楚 `/` 與 `//`，並把小數輸出成題目要求的位數。  
**積木／Python 對照**：Scratch／Blockly 有四捨五入積木，但沒有「不足位數補 0」的格式化能力，本概念改為 Python 限定教學。  
**教師提問**：「`100 / 3` 會印出一長串小數，題目只要小數點後兩位時，要怎麼辦？」

#### 教師例題：均分帳單

輸入總金額與人數（同一行、空白分隔），輸出每人應付金額，固定顯示小數點後兩位。

```text
輸入：100 3
輸出：33.33
```

老師示範重點：`/` 一定得到小數，`8 / 2` 是 `4.0` 不是 `4`；要固定幾位小數，用 `f"{x:.2f}"` 這種格式碼，小數第二位之後四捨五入，不足的位數會補 0。

#### 變體 A（中年級核心）：攝氏轉華氏

輸入攝氏溫度（整數），換算成華氏溫度，輸出固定顯示小數點後一位。轉換公式是「華氏 = 攝氏 × 9 / 5 + 32」。

```text
輸入：20
輸出：68.0
```

#### 變體 B（高年級追加）：整除還是小數

輸入兩個正整數 a 與 b（同一行、空白分隔）。第一行輸出 `a // b` 的整除結果，第二行輸出 `a / b` 的小數結果，固定顯示小數點後三位。

```text
輸入：7 2
輸出：
3
3.500
```

**常見錯誤**：只用 `round()` 導致 `3.5` 印成 `3.5` 而不是 `3.50`；把 `//` 用在需要小數的題目上，得到被截斷的整數。  
**通關標準**：能說出「就算答案剛好是整數，為什麼還是要用 f-string 固定小數位數」。  
**未來連接**：Judge-073、LV.2 的資料格式化輸出。

**工具限制備註**：本概念是第一階段唯一標記 🐍 Python 限定的關卡（對應 ThinkLab 網站 `allowedLanguages: ['python']`）。原因是 Scratch／Blockly 都有四捨五入積木，但沒有「不足位數補 0」的格式化能力，核心題與變體 B 的測資都需要補 0 才能通過。課堂若仍想先用積木暖身，可只示範四捨五入，不強求補 0 對齊，正式判分則統一走 Python。

### 概念 9：比較、真假與二選一

**教學目標**：學生理解條件是一個答案只有「成立／不成立」的問題，能處理門檻邊界。  
**積木／Python 對照**：比較積木加「如果／否則」↔ `if ... else ...`。  
**教師提問**：「剛好等於門檻時，應該走哪一條路？」

#### 教師例題：是否可以搭乘

輸入身高。身高大於或等於 120 時輸出 `可以`，否則輸出 `再等等`。

```text
輸入：120
輸出：可以
```

至少測試 119、120、121，讓學生看見邊界。

#### 變體 A（中年級核心）：及格判斷

輸入分數。60 分以上輸出 `通過`，否則輸出 `再練習`。

```text
輸入：59
輸出：再練習
```

#### 變體 B（高年級追加）：密碼相同嗎

依序輸入兩個整數。相同輸出 `相同`，不同輸出 `不同`。

```text
輸入：
42
24
輸出：
不同
```

**常見錯誤**：`>` 與 `>=` 混用；把「否則」接到錯誤的如果；只測試遠離門檻的數。  
**通關標準**：能主動提出「小於、等於、大於門檻」三種測試。  
**未來連接**：資料篩選、碰撞規則、搜尋、輸入檢查。

### 概念 10：多種情況與規則順序

**教學目標**：學生能處理三種以上互斥結果，理解規則檢查順序會影響答案。  
**積木／Python 對照**：巢狀「如果／否則」或多分支 ↔ `if / elif / else`。  
**教師提問**：「每個輸入最後是不是只會得到一種結果？有沒有漏掉的情況？」

#### 教師例題：溫度提示

輸入整數溫度：

- 30 以上輸出 `炎熱`
- 20～29 輸出 `舒適`
- 19 以下輸出 `偏涼`

```text
輸入：25
輸出：舒適
```

測試 19、20、29、30，並畫成三段數線。

#### 變體 A（中年級核心）：星星等級

輸入星星數：

- 10 以上輸出 `金牌`
- 5～9 輸出 `銀牌`
- 0～4 輸出 `銅牌`

```text
輸入：7
輸出：銀牌
```

#### 變體 B（高年級追加）：同時符合時先選誰

輸入正整數：

- 如果同時是 2 和 3 的倍數，輸出 `兩者`
- 否則如果是 2 的倍數，輸出 `二`
- 否則如果是 3 的倍數，輸出 `三`
- 都不是則輸出 `無`

```text
輸入：12
輸出：兩者
```

**常見錯誤**：範圍中間有洞或重疊；先檢查較寬的規則，導致特殊情況永遠走不到；忘記最後的其他情況。  
**通關標準**：能為每個分支各設計一個測試，並說明邊界屬於哪一段。  
**未來連接**：遊戲狀態機、分類問題、複合布林條件。

### 概念 11：布林值與 and／or／not

**教學目標**：學生能把「成立或不成立」本身當成一個值，並用 `and`、`or`、`not` 組合多個條件。  
**積木／Python 對照**：「而且」「或者」「不是」積木 ↔ Python `and`、`or`、`not`。  
**教師提問**：「`x > 5` 這種比較，算出來的答案是不是也可以直接印出來、存進變數？」

#### 教師例題：可以搭乘嗎

輸入身高與年齡（同一行、空白分隔），身高至少 120 公分且年齡至少 6 歲才能搭乘。直接輸出這個條件成立與否的布林值，不需要寫 `if`。

```text
輸入：125 7
輸出：True
```

老師示範重點：比較式算出來的結果就是 `True` 或 `False` 兩個布林值之一，可以直接 `print()`；`and` 要兩邊都成立，`or` 任一邊成立就好，`not` 把真假反過來。

#### 變體 A（中年級核心）：是週末嗎

輸入代表星期幾的整數（1 到 7，7 代表星期日），直接輸出這個數字是不是週末（6 或 7）的布林值。

```text
輸入：6
輸出：True
```

#### 變體 B（高年級追加）：是不是不及格

輸入一個分數，直接輸出這個分數是不是不及格（低於 60 分）的布林值，用 `not` 對「及格」取反來寫出這個判斷式。

```text
輸入：45
輸出：True
```

**常見錯誤**：以為布林值一定要搭配 `if` 才能使用，多寫了不必要的判斷式；把 `and` 與 `or` 的意思用反，該兩者都成立卻只檢查其中一個。  
**通關標準**：能不寫 `if`，只靠一行 `print()` 加比較式就得到正確的 `True`／`False`。  
**未來連接**：LV.2 的 M06（線性搜尋，回收布林值概念）、複合條件、決策樹。

### 概念 12：固定或指定次數重複

**教學目標**：學生看出重複模式，能用迴圈取代重複貼上的指令。  
**積木／Python 對照**：「重複 N 次」↔ `for` 迴圈。  
**教師提問**：「如果要做 100 次，你願意貼上 100 組積木嗎？」

#### 教師例題：加油隊

輸入 N，輸出 N 行 `加油`。

```text
輸入：3
輸出：
加油
加油
加油
```

先人工貼 3 次，再改成重複積木，對比兩者。

#### 變體 A（中年級核心）：印出星星

輸入 N，輸出 N 行 `*`。

```text
輸入：4
輸出：
*
*
*
*
```

特別測試 N=1，避免多一次或少一次。

#### 變體 B（高年級追加）：從 1 數到 N

輸入 N，依序輸出 1 到 N，每個數字一行。

```text
輸入：4
輸出：
1
2
3
4
```

**常見錯誤**：把輸入 N 當成要輸出的文字；迴圈多跑或少跑一次；迴圈內外縮排／包覆錯誤。  
**通關標準**：能圈出「重複的部分」，並預測 N=1、N=5 的輸出行數。  
**未來連接**：走訪字串與清單、動畫、圖案、演算法效率。

### 概念 13：重複直到 — while 迴圈

**Badge**：`while`

**教學目標**：學生能分辨「已知重複次數」與「不知次數，但知道什麼時候停止」，並在每一輪更新影響條件的變數。

**積木／Python 對照**：Scratch 的「重複直到」、Blockly 的 `controls_whileUntil` ↔ Python `while`。

**教師提問**：「如果不知達標要幾天，我們還能事先寫出重複次數嗎？」

`for` 適合已經知道要重複幾次的情況；`while` 適合不知道次數，但能描述繼續條件的情況。Scratch 沒有直接名為 `while` 的積木，主要使用「重複直到」：它在條件成立時停止；Python `while` 則在條件成立時繼續。這是工具的表達差異，課堂先要學會用「什麼時候繼續／什麼時候停止」檢查條件。

#### 教師例題：存錢計畫

輸入每天存入的正整數 N 和目標 G。從 0 元開始，每天存 N 元，輸出第幾天第一次達到或超過目標。

```text
輸入：10 35
輸出：4
```

用追蹤表記錄 `days` 與 `saved`：`(0, 0) → (1, 10) → (2, 20) → (3, 30) → (4, 40)`。每一輪都必須讓 `saved` 接近目標。

#### 變體 A（中年級核心）：減到零

輸入正整數 N，只要 N 大於 0 就輸出 N，然後將 N 減 3；停止後不輸出 0 或負數。

```text
輸入：10
輸出：
10
7
4
1
```

#### 變體 B（高年級追加）：猜數字追蹤

輸入 1 到 100 之間的目標數。程式從中間值 50 開始，每次根據「太大／太小」縮小一半範圍，輸出找到目標所需的步數。先用紙筆追蹤上界、下界和本次猜測，作為未來二分搜尋的直覺鋪墊。

**常見錯誤**：忘記更新條件變數而無限重複；把 Scratch「重複直到」的停止條件與 Python `while` 的繼續條件當成同一方向；先更新再輸出，造成少一次或多一次。

**通關標準**：能先說明繼續條件和停止條件，並指出迴圈內哪個更新會讓程式最後停下。

**未來連接**：輸入驗證、狀態模擬、二分搜尋、不定次數的遊戲回合。

### 概念 14：計數器

**教學目標**：學生能從 0 開始，每遇到一筆符合條件的資料就把計數器加 1。  
**積木／Python 對照**：「將 count 設為 0」「將 count 改變 1」↔ 初始化、條件、更新。  
**教師提問**：「我們要記的是資料本身，還是符合條件的資料有幾筆？」

#### 教師例題：亮燈數量

第一個輸入是資料筆數 N，接著輸入 N 個 0 或 1；1 代表亮燈。輸出亮燈數量。

```text
輸入：
5
1
0
1
1
0
輸出：
3
```

追蹤 `count`：0 → 1 → 1 → 2 → 3 → 3。

#### 變體 A（中年級核心）：熄燈有幾盞

輸入方式同上，但這次要輸出狀態為 0 的燈有幾盞。這不是只換故事，而是要把「符合條件」由 1 改為 0。

```text
輸入：
4
0
0
0
0
輸出：
4
```

#### 變體 B（高年級追加）：達到門檻的人數

第一行輸入 N，接著輸入 N 個分數，輸出大於或等於 60 的人數。

```text
輸入：
5
60
59
80
42
100
輸出：
3
```

**常見錯誤**：count 沒先設為 0；每一輪都把 count 重設；不論是否符合都加 1；最後輸出最後一筆資料而非 count。  
**通關標準**：能畫出逐輪追蹤表，並通過「無人符合、全部符合、剛好等於門檻」。  
**未來連接**：統計、字元頻率、搜尋結果數、資料分析。

### 概念 15：累加器與小型綜合題

**教學目標**：學生能從 0 開始，把每一筆資料加入目前總和，並區分「有幾筆」和「合計多少」。  
**積木／Python 對照**：「將 total 設為 0」「將 total 改變目前數值」↔ running total。  
**教師提問**：「count 每次加 1；total 每次應該加什麼？」

#### 教師例題：一週閱讀頁數

先輸入天數 N，再輸入每天閱讀頁數，輸出總頁數。

```text
輸入：
4
5
8
0
7
輸出：
20
```

追蹤 `total`：0 → 5 → 13 → 13 → 20；特別指出輸入 0 時總和不變，但那一天仍算一筆資料。

#### 變體 A（中年級核心）：從 1 加到 N

輸入正整數 N，輸出 `1 + 2 + ... + N` 的總和。這次不逐筆輸入資料，而是使用概念 12 的迴圈編號。

```text
輸入：
5
輸出：
15
```

與概念 14 比較：這裡不是每次固定加 1，而是依序加上 1、2、3、4、5。

#### 變體 B（高年級追加）：只加通過的分數

第一行輸入 N，接著輸入 N 個分數，只把大於或等於 60 的分數加入總和，輸出總和。

```text
輸入：
5
60
59
80
42
100
輸出：
240
```

**常見錯誤**：total 沒初始化；每輪覆蓋 total 而非加上去；把筆數 N 加入總和；混淆計數器和累加器。  
**通關標準**：能同時口頭回答「符合幾筆」和「合計多少」，並指出兩個變數的不同。  
**未來連接**：平均數、最大最小值、清單走訪、前綴和與資料分析。

- 字串逐字處理
- 清單的建立、讀取與修改
- 走訪清單
- 線性搜尋
- 統計、最大最小與簡單排序觀察

### 第四階段：拆解與重用

- 自訂積木／函式
- 參數與回傳值
- 把大問題拆成小任務
- 用測試資料除錯
- 閱讀與修改別人的程式

### 第五階段：小型專題與演算法萌芽

- 座標與格子地圖
- 規則模擬
- 簡單編碼與資料轉換
- 搜尋策略比較
- Scratch 互動作品和相同邏輯的文字判題版本

### 第六階段：從積木過渡到 Python

- 一次只替換一種表示法：先輸出，再變數，再條件，再迴圈。
- 同一題先做積木版，再讀等價 Python；不要同時換題目和語言。
- 建立「積木 → 流程圖／虛擬碼 → Python」三欄對照表。
- 最後才加入字串索引、串列語法與函式定義等 Python 特有表示。

```text
第一階段基礎
  ├─ 數與輸出（5、6、7、8）→ 位數拆解與進位 → 統計與格式化報表
  ├─ 條件（9、10、11）→ 複合條件 → 決策樹 → 規則模擬
  ├─ 迴圈（12、13）→ 巢狀迴圈 → 字串／清單走訪
  ├─ 狀態（4）→ 計數／累加（14、15）→ 最大最小 → 資料分析
  └─ 精確步驟（1、2、3）→ 除錯與測試 → 函式拆解 → Python/OJ
```

這條路線刻意把遞迴、二維陣列、雜湊、正式複雜度分析與競賽技巧留到基礎穩固之後。學生若能說清楚變數如何改變、條件何時成立、迴圈每輪做什麼，後續換工具或語言會順利許多。
