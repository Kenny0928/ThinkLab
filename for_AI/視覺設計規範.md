# 🎨 ThinkLab 視覺設計規範（Design System）

本文件是 ThinkLab 所有頁面的**視覺契約**。新增頁面、新增區塊、修改樣式時一律以此為準。
與 `AI_AGENT_工作流與開發規範.md` 的關係：那份管「功能與資料流程」，這份管「長什麼樣子」。兩份都要遵守。

> **這份文件描述的是現況，不是願景。** 所有數值都能在程式碼中找到對應。
> 若你改動了樣式而使本文件失準，請一併更新本文件。

---

## 〇、三條最高原則

動手前先讀這三條。後面所有規則都是這三條的展開。

### 1. 畫面上最亮、最大、周圍最空的東西，就是使用者會先看的東西

因此**最重要的內容必須佔據那個位置**。常見的錯誤是把它讓給了：品牌 logo、載入狀態、難度標籤、裝飾性徽章。

每設計一個畫面，先回答：**這一頁的使用者要做的那一件事是什麼？** 那件事必須是視覺上最重的。

### 2. 每個畫面只能有一個「主要動作」

主要動作＝填滿 `--accent` 的實心塊，**一個畫面只准一個**。
其餘一律降級為外框按鈕（次要）或純文字連結（第三級）。
若你發現一個畫面有兩個藍色實心按鈕，代表層級沒有想清楚。

### 3. 顏色是用來「指路」的，不是用來裝飾的

每個顏色只有一個職務（見 §二）。一旦同一個顏色同時代表三件事，它就失去了指路能力。
**不確定要用什麼顏色時，答案是「不上色」** —— 用 `--text-muted` 或 `--text-subtle`。

## 一、設計權杖（Design Tokens）

### ⚠️ 最重要的一件事：本專案有兩套權杖命名，值完全相同

歷史因素造成。**新增檔案時請選對一套，不要混用，也不要自創第三套。**

| 用途 | A 套（`algoplay/core/base.css`、`test/flow-lab.css`） | B 套（`judge.html`、`beginner.html`） | 值 |
|---|---|---|---|
| 頁面底色 | `--paper` | `--bg` | `#0c0d12` |
| 主要文字 | `--ink` | `--text` | `#f5f7fa` |
| 次要文字 | `--muted` | `--text-muted` | `#94a3b8` |
| 第三級文字 | `--subtle` | `--text-subtle` | `#6f7f97` |
| 面（卡片、列頭） | `--soft` | `--surface` | `#141720` |
| 浮起面（按鈕底） | `--raised` | `--surface2` | `#1a1e28` |
| 下沉面（程式碼區） | `--sunken` | `--surface-dark` | `#10131b` |
| 分隔線 | `--line` | `--border` | `#262a33` |
| 強分隔線 | `--line-strong` | `--border-strong` | `#343d50` |
| 主色 | `--accent` | `--accent` | `#3b82f6` |
| 主色 hover | `--accent-hover` | `--accent-hover` | `#4b7de7` |
| 主色淡底 | `--accent-soft` | `--accent-soft` | `rgba(59,130,246,0.14)` |
| 主色亮字 | `--accent-ink` | `--accent-ink` | `#9ec5ff` |
| 成功／通過 | `--green` | `--success` / `--easy` | `#63d6ad` |
| 注意／等待 | `--amber` | `--warning` / `--medium` | `#f1bd62` |
| 錯誤／失敗 | `--red` | `--danger` / `--hard` | `#ff8192` |
| 資訊 | `--cyan` | `--info` | `#6dd5ed` |
| 強調（無語意） | `--violet` | （未定義） | `#b69cff` |

**選哪一套？**

- 新頁面掛 `algoplay/core/base.css` → 用 **A 套**（這是首選，能直接拿到 `.site-header`、`.page`、按鈕等現成元件）。
- 修改 `judge.html` / `beginner.html` → 用 **B 套**（該檔案內已定義）。
- 修改 `test/flow-lab.css` → 用 **A 套**。

### 🪤 陷阱：`--radius` 在兩套裡意思相反

| | A 套 | B 套 |
|---|---|---|
| `--radius` | **11px**（大） | **7px**（小） |
| 另一個 | `--radius-sm` = 7px | `--radius-lg` = 11px |

**跨檔案複製 `border-radius: var(--radius)` 會得到不同結果。** 複製樣式時務必確認。

### 圓角使用時機

| 尺寸 | 用在 |
|---|---|
| 4–5px | 徽章內的小方塊、行內 `code` |
| 7px | 按鈕、輸入框、下拉選單、小卡片 |
| 10–11px | 面板、大卡片、對話框 |
| 999px | 膠囊標籤（pill） |

### 字體

```css
--font: "Plus Jakarta Sans", "Noto Sans TC", "Segoe UI", system-ui, sans-serif;
--mono: "Fira Code", "SFMono-Regular", Consolas, monospace;
```

**新頁面必須在 `<head>` 載入這三個字族**，否則會掉回系統字體，跟其他頁對不起來：

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Fira+Code:wght@400;500;700&family=Plus+Jakarta+Sans:wght@400;600;700;800&family=Noto+Sans+TC:wght@400;500;700&display=swap" rel="stylesheet">
```

**必須關閉連字（ligatures）**：

```css
*, *::before, *::after { font-variant-ligatures: none !important; }
```

> 為什麼：Fira Code 會把 `<=` `==` `!=` 合成單一字形。學生照著畫面打字時會打不出來。這是教學平台的硬性要求，不是美感偏好。

## 二、顏色的職務分工

**每個顏色只做一件事。** 違反這張表就是 bug。

| 顏色 | 唯一職務 | 允許出現的地方 |
|---|---|---|
| `--accent` 藍 #3b82f6 | **可以點的東西 + 主要動作** | 主要按鈕、連結、小節標題的左側短線、目前所在位置的標示 |
| `--accent-ink` #9ec5ff | 深色底上的**連結文字** | 題目名稱、`.text-button`、行內程式碼 |
| `--success` 綠 #63d6ad | **只代表「通過 / 完成」** | AC 判定、已完成狀態、檢查點標題 |
| `--warning` 琥珀 #f1bd62 | **只代表「注意 / 等待 / 中等」** | TLE、等待輸入、思考題提示、常見錯誤 |
| `--danger` 紅 #ff8192 | **只代表「錯誤 / 失敗」** | WA、RE、刪除動作、驗證錯誤 |
| `--info` 青 #6dd5ed | 中性資訊、流程節點 | 流程圖的輸入節點、補充說明 |
| `--violet` 紫 #b69cff | 分類用（無情緒） | 流程圖的處理節點、LV.3 徽章 |

### 禁止事項

- ❌ 用綠色表示「這裡有東西」——綠色只能是「通過了」。
- ❌ 用紅色表示「重要」——紅色只能是「錯了」。
- ❌ 難度、標籤、狀態同時上滿色。決定誰最重要，其餘降為灰。
- ❌ 直接寫 Tailwind 那組飽和色（`#22c55e` `#ef4444` `#f59e0b` `#06b6d4`）。
  本站用的是它們的柔和版本；寫死飽和色會在深色底上刺眼，且跟其他頁對不上。

### 深色底上的文字對比

本站所有語意色在頁面底色 `#0c0d12` 上的實測對比（WCAG AA 內文門檻為 4.5:1）：

| 權杖 | 對比 | 判定 |
|---|---|---|
| `--text` #f5f7fa | 18.09:1 | ✓ |
| `--warning` #f1bd62 | 11.27:1 | ✓ |
| `--accent-ink` #9ec5ff | 10.98:1 | ✓ |
| `--success` #63d6ad | 10.86:1 | ✓ |
| `--danger` #ff8192 | 8.14:1 | ✓ |
| `--text-muted` #94a3b8 | 7.57:1 | ✓ |
| `--accent` #3b82f6 | 5.28:1 | ✓（勉強，見下） |
| `--text-subtle` #6f7f97 | 4.77:1 | ✓（勉強，只用於最次要資訊） |

**慣例：`--accent` 雖然通過 AA，但當文字用時一律改用 `--accent-ink`。**
理由不是無障礙，而是可掃視性——5.28:1 在一長串列表裡仍然偏暗，
而本站受眾含國小學生。`--accent` 保留給**填滿的底色**與**幾何元素**（短線、邊框、圓點）。

`--text-subtle` 只用於題號、時間戳這類「存在即可、不需要被讀」的資訊，不要拿來排內文。

> 改動任何顏色後，請重新計算對比再寫進本表，不要沿用網路上該色在白底的數值——
> 同一個藍在白底是 3.68:1，在本站深底是 5.28:1，差很多。

## 三、版面骨架

### 頁首（每一頁都必須長一樣）

頁首是全站唯一每頁都出現的元件，**它的一致性優先於任何頁面的個別需求**。

```html
<header class="site-header">
  <a class="brand" href="index.html"><span class="brand-icon" aria-hidden="true"></span>ThinkLab</a>
  <span class="header-divider"></span>
  <span class="header-label">目前頁面名稱</span>
  <nav><a href="...">其他入口</a><a href="...">其他入口</a></nav>
</header>
```

| 項目 | 規格 |
|---|---|
| 高度 | **52px**（所有頁面一致，不得更動） |
| 定位 | `position: sticky; top: 0; z-index: 30` |
| 左右內距 | `clamp(16px, 3vw, 28px)` |
| 底色 | `rgba(12,13,18,0.9)` + `backdrop-filter: blur(12px)` |
| 底線 | `1px solid var(--line)` |
| 品牌方塊 | 18×18px、`border-radius: 4px`、`background: var(--accent)` |
| 品牌字 | `1.15rem / 800 / letter-spacing: -0.03em` |
| 麵包屑與 nav | `13px`，`--muted`，hover 轉白 |
| nav 位置 | `margin-left: auto`（靠右） |

> 若頁面下方還有第二層固定列（如 `guide.html` 的章節捷徑），它的 `top` 必須是 **52px**，
> 且該區塊的 `scroll-margin-top` 要留 **112px**（52 + 捷徑列高度），否則錨點跳轉會被蓋住。

### 內容容器

```css
.page { width: min(1180px, 100%); margin: 0 auto; padding: 32px clamp(16px, 4vw, 40px) 72px; }
```

工具型頁面（流程圖實驗室、Judge 解題頁）可用滿版三欄，不受 1180px 限制。

### 背景

首頁與說明頁使用共用的格線背景，直接複製這段標記即可（樣式已在 `base.css`）：

```html
<div class="bg-canvas" aria-hidden="true"><div class="bg-grid"></div><div class="bg-aurora"></div></div>
```

工具型頁面（編輯器、畫布）**不加背景格線**——會干擾內容。

## 四、文字排版

### 🔑 行長：`--measure: 42em`

**這是本規範中最容易被違反、影響也最大的一條。**

中文舒適閱讀是每行 **25–40 個全形字**。超過 45 字，眼睛讀完一行往左回掃時會找不到下一行的行首，導致重讀或跳行。

```css
--measure: 42em;   /* ≈ 42 個全形字 */
```

**用 `em` 而不是 `px` 是關鍵**：字級變小時欄寬跟著變窄，「字／行」才維持不變。
16.8px 的內文得到 706px，15px 的註解得到 632px——兩者讀起來一樣舒服。

**套用對象：所有純文字區塊。**

```css
.你的內文, .你的說明框, .你的提示, .你的清單 { max-width: var(--measure); }
```

**例外（不套）**：程式碼編輯器、畫布、資料表格、並排的範例輸入／輸出以外的寬版工具。
這些真的需要寬度。但除此之外，**一個閱讀欄應該只有一條右邊界**——別讓文字停在 700px 而說明框跑到 1000px。

### 字級階層：只准三階

平坦的字級是「整頁看起來沒有重點」的主因。

| 層級 | 大小 | 用在 |
|---|---|---|
| 小節標題 | `1.22rem` / `750` | 段落標題，**必須明顯大於內文** |
| 內文 | `1.0 – 1.05rem` | 主要敘述 |
| 註解 | `0.94rem` | 提示、補充、次要說明 |

- ❌ 標題只比內文大 4%（例如 1.08rem vs 1.04rem）——那等於沒有標題。**至少差 15%。**
- ❌ 註解小於 `0.9rem`。本站受眾含國小學生，13px 中文太小。

頁面主標題另外一階：`clamp(1.7rem, 3.4vw, 2.4rem) / 800 / letter-spacing: -0.02em`。

### 行高

| 用途 | 行高 |
|---|---|
| 中文內文 | **1.85** |
| 中文註解、短文字 | **1.8** |
| 表格列、按鈕、標籤 | 1.3 – 1.5 |

中文字身比西文飽滿，需要比英文更大的行距。**不要用 1.5 排中文內文。**

### 段落留白要有「親疏」

標題離**上一段**要遠、離**自己的內文**要近。否則讀者分不出哪段屬於哪個標題。

```css
.card-heading { padding: 36px 0 12px; }   /* 上 36px、下 12px，比例 3:1 */
```

### 中文排版細節

```css
.你的內文 { text-wrap: pretty; }   /* 避免段落最後一行只剩一兩個孤字 */
```

中文與西文之間要留氣口。行內 `code` 用 `margin: 0 1px` 處理；純文字則在內容裡手動加半形空格（本站既有內容已採此慣例，例如「使用 `set` 與 `dict` 做⋯」）。

### 行內程式碼

教材的中文敘述裡夾著程式碼時，**程式碼必須看得出來是程式碼**。
`beginner.html` 有一個 `withCode()` 函式做這件事：

```js
// 只把「識別字後面直接接 () 或 []」的片段包成 <code>
const CODE_TOKEN = /[A-Za-z_][A-Za-z0-9_.]*(?:\([^()]*\)|\[[^\[\]]*\])/g;
```

會標：`print()`、`text[::-1]`、`map(int, ...)`、`O(1)`
不標：`set`、`dict`、`YES`、`N`、`B (兩個數)`、`（沒有輸入）`

**原則是寧可漏標，也不要標錯。** 新增教材文字時沿用此規則；若你要擴充比對範圍，必須先用真實教材字串測過誤判。

行內 `code` 樣式：

```css
code {
  padding: 1px 5px;            /* 垂直只給 1px，否則會頂開行高 */
  margin: 0 1px;               /* 中文與西文之間的氣口 */
  border-radius: 4px;
  color: #bfdbfe;
  background: rgba(59, 130, 246, 0.13);
  box-shadow: inset 0 0 0 1px rgba(59, 130, 246, 0.16);
  font: 0.9em var(--mono);
  white-space: nowrap;         /* 不讓 map(int, ...) 斷在中間 */
}
```

## 五、元件模式

以下每個模式都已在站上使用。**新增類似需求時請沿用，不要另創寫法。**

### 主要按鈕（一頁一個）

```css
background: var(--accent); border-color: var(--accent); color: #fff; font-weight: 650;
```

### 次要按鈕

```css
background: transparent; border: 1px solid var(--border); color: var(--text-muted);
/* hover: border-color: var(--border-strong); color: var(--text); */
```

### 文字連結按鈕

```css
border: 0; background: transparent; padding: 0; color: var(--accent-ink); font-size: 13px;
```

### 小節標題地標（長捲動頁面必備）

在長段落裡，小節標題是讀者的定位點，**必須比內文更亮，不是更淡**。加一條左側藍線讓每段的起點一眼可見：

```css
.section-title {
  position: relative; padding-left: 12px;
  font-size: 0.84rem; font-weight: 700; color: var(--text);
  margin: 26px 0 10px;
}
.section-title::before {
  content: ""; position: absolute; left: 0; top: 0.3em; bottom: 0.3em;
  width: 3px; border-radius: 2px; background: var(--accent);
}
```

> ❌ 不要用 `text-transform: uppercase` + 大 `letter-spacing` 排中文小標，中文不會變大寫，只會被拆散。

### 步驟清單（軸線式，不要一句一個框）

連續的流程用一條軸線串起來。**不要每個步驟包一個外框**——十幾個字配一個 border + background，框的重量遠大於內容，而且把一段連續流程切成互不相干的碎片。

```css
.step-list { position: relative; padding-left: 34px; list-style: none; }
.step-list::before {           /* 垂直軸線 */
  content: ""; position: absolute; top: 16px; bottom: 16px; left: 11px;
  width: 2px; border-radius: 2px;
  background: linear-gradient(180deg, rgba(59,130,246,0.45), rgba(59,130,246,0.12));
}
.step-list li { position: relative; padding: 8px 0; border: 0; background: transparent; }
.step-list li::before {        /* 編號圓點，用 --bg 蓋住背後的軸線 */
  content: attr(data-step); position: absolute; left: -34px; top: 12px;
  width: 23px; height: 23px; display: grid; place-items: center;
  border-radius: 50%; color: var(--accent-ink); background: var(--bg);
  box-shadow: inset 0 0 0 1px var(--border-strong);
  font-size: 0.68rem; font-weight: 800;
}
```

### 徽章的兩種重量

同一列裡若有多種標籤，**只有一種可以是實心色塊**，其餘降為點或外框。

```css
/* 重（分組用，例如學習階段）：淡色底 + 亮字 */
.badge-stage-x { background: rgba(59,130,246,0.16); color: #93c5fd; border-radius: 999px; padding: 2px 9px; }

/* 輕（輔助資訊，例如難度）：一顆點 + 文字，沒有底色 */
.badge-difficulty { background: transparent; padding: 0; display: inline-flex; align-items: center; gap: 6px; }
.badge-difficulty::before { content: ""; width: 6px; height: 6px; border-radius: 50%; background: currentColor; }

/* 最輕（標籤）：只有 1px 外框 */
.tag { background: transparent; box-shadow: inset 0 0 0 1px var(--border); color: var(--text-subtle); }
```

### 說明框（callout）

左側 3px 色條 + 該色的 8% 淡底。**不要用四邊外框**，會跟卡片混淆。

```css
.callout { padding: 16px 18px; border-left: 3px solid var(--accent);
           border-radius: 0 var(--radius) var(--radius) 0;
           background: rgba(59, 130, 246, 0.09); max-width: var(--measure); }
```

色條顏色依語意選：概念說明用 `--accent`、思考題用 `--warning`、檢查點用 `--success`。

### 狀態與結果

判題／執行結果**收合時也必須看得出成敗**。用 `data-` 屬性帶狀態，CSS 負責上色：

```css
.results-panel[data-verdict="AC"]  { border-left: 3px solid var(--success); }
.results-panel[data-verdict="WA"]  { border-left: 3px solid var(--danger); }
.results-panel[data-verdict="TLE"] { border-left: 3px solid var(--warning); }
```

> `data-verdict` 只用於上色，**不得參與任何判定邏輯**。

### 表格列表

| 規則 | 說明 |
|---|---|
| 列高固定 | `td { height: 52px }` + `table-layout: fixed`。列高忽高忽低會打斷掃視節奏 |
| 可點的那一欄最亮 | 用 `--accent-ink` + `font-weight: 600` |
| 會溢出的欄位 | `white-space: nowrap; overflow: hidden;` + 右緣 `mask-image` 淡出，**不要換行** |
| 索引欄 | `var(--mono)` + `--text-subtle`，壓到最暗 |
| 手機 | 砍掉次要欄位（`display: none`），不要讓使用者左右滑 |

### 程式碼編輯器

CodeMirror 用 Dracula 語法色，但**底色必須覆寫成站上的深色面**，否則 `#282a36` 的紫灰跟站上的藍黑對不起來：

```css
.editor-area .CodeMirror, .editor-area .CodeMirror-scroll { background: var(--surface-dark) !important; }
.CodeMirror-gutters { background: var(--surface-dark) !important; border-right: 1px solid var(--border) !important; }
.CodeMirror-linenumber { color: var(--text-subtle) !important; }
```

> 例外：Scratch 編輯器（`assets/scratch-editor.html`）是官方 Scratch Blocks，本身就是亮色介面，**維持亮色即可**，不要強行套深色。

## 六、無障礙與響應式

### 必要項

```css
:focus-visible { outline: 2px solid #8eb0ff; outline-offset: 3px; }

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

- 所有可點元素都要有可見的 focus 樣式。
- 用 `<span onclick>` 當連結時，必須補 `role="link" tabindex="0"` 與 `onkeydown` 的 Enter／Space 處理。
- 純裝飾元素加 `aria-hidden="true"`。
- 內文與底色對比至少 **4.5:1**；大字（≥18.66px 粗體或 ≥24px）至少 **3:1**。

### 斷點

| 寬度 | 處理 |
|---|---|
| ≤ 980px | 多欄改單欄；篩選列縮成 2–3 欄 |
| ≤ 768px | 表格砍次要欄位；雙欄工作區改上下堆疊；頁首允許換行 |
| ≤ 520px | 網格全部單欄；主標題縮一階 |

手機最小左右留白 **16px**，且不得出現橫向捲動。

### 新頁面的 `<head>` 檢查清單

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
<meta name="theme-color" content="#0c0d12">
<meta name="description" content="...">
<title>頁面名稱｜ThinkLab</title>
<link rel="icon" href="data:image/svg+xml,...">   <!-- 藍底圓角方塊，沿用既有頁面 -->
<!-- 三個字族的 Google Fonts -->
```
