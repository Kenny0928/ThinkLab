## 改編原則

- 原站以 `prompt`／`alert` 互動並忽略所有空白比對；ThinkLab 採 stdin／stdout 與末尾空白相容的完整比對，因此每題都重寫輸入、輸出格式，並把原題未定義的情況（並列、邊界、0、四捨五入方式）明確寫入題意。
- 每題至少 3 組公開範例、10 組以上正式測資，期望輸出由獨立 oracle 產生，不直接沿用原站答案。
- 原站範例與原站測資都會以參考解答重跑（忽略空白後比較），確認改編沒有改變原題答案。
- 涉及小數四捨五入的題目（237、242、253、254、257），測資避開浮點誤差可能改變結果的臨界值，並在限制中註明。

## 檔案

- `imports.json`：每題的 Judge 題號、原站題號、分類、題文 SHA-256 與改編說明，以及未匯入清單。
- `../../scripts/bdesigner_import/`：題目規格、參考解答、oracle 與測資的產生與驗證腳本（`batch1.py`～`batch5.py`）。

## 重新驗證

在儲存庫根目錄執行：

```bash
for b in 1 2 3 4 5; do python3 scripts/bdesigner_import/batch$b.py; done
python3 scripts/verify_problems.py
```

各 batch 腳本預設只驗證不寫檔；加上 `--write` 才會依腳本內規格覆寫 `problems/NNN.json`、`solutions/NNN.py` 並更新 `problems/index.json` 同題號項目。修改題目時請改腳本內規格後重建，`docs/題庫總覽與學習階梯.md` 需另外同步。
