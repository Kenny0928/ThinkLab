# ThinkLab 課程與題庫總綱（LV.2／LV.3）

## 一、內容目標

本輪擴充承接LV.1講義的 15 個基礎概念（編號 1–15，第二輪補完後已全部重排為連續整數），補齊首頁規劃中的LV.2與LV.3內容。設計原則是「一次只增加一個主要負擔」，每一關都明確標示先備能力、當關新能力與下一關連接。

```text
LV.1：輸入輸出、變數、型別轉換、算術、整除與餘數、小數格式化、條件、布林值、for、while、計數、累加
  ↓
LV.2：字串處理與組裝 → 清單增刪與統計 → 數字拆解 → 搜尋與更新 → 二維資料 → 函式與除錯
  ↓
LV.3：效率 → 排序（基礎與進階）→ 前綴和 → 雙指標 → 二分搜尋 → stack/queue → 圖與樹 → 遞迴與記憶化 → 貪心與 DP（一維與二維）
  ↓
綜合題：自行選擇資料結構與演算法，並說明複雜度
```

## 六、每關固定教學節奏

每關沿用 LV.1「先預測、再拆解、動手測試」的節奏，但 LV.2／LV.3 多加一個反思層：

1. **回收先備**：用一題 3 分鐘暖身確認前一能力。
2. **觀察與預測**：先手動追蹤一個小輸入，不先給完整答案。
3. **核心講解**：用一個模型圖或追蹤表說清楚新概念。
4. **核心題 C**：提供部分程式骨架與三段提示。
5. **變體 A**：同概念直接鞏固，提示較少。
6. **變體 B**：換資料型態或增加一個已學概念，檢查遷移。
7. **反例與邊界**：至少測一般、最小、容易犯錯三類輸入。
8. **出口檢核**：能解釋、能自行設計測資、能指出複雜度或資料流。

### 變體的角色

- **核心題 C**：完整示範新概念，讓學生能跟著完成。
- **變體 A（鞏固）**：只改操作目標，不增加新觀念。
- **變體 B（遷移）**：保留主概念，結合一個已學能力或換情境；不得偷偷加入下一關知識。

## 八、三種實作環境的支援邊界

本節標記的是目前課程工具能否直接實作，不是說資料結構或演算法只屬於某一種程式語言。

| 概念／實作 | Scratch | Blockly | Python | 課程處理 |
|---|---|---|---|---|
| 不定次數迴圈 | 「重複直到」，停止條件成立時結束 | `controls_whileUntil` 可選 while／until | `while` 在繼續條件成立時執行 | 概念 13 明說工具限制與條件方向 |
| 集合／雜湊集合 | 沒有原生對應 | 目前課程工具箱沒有對應積木 | `set` | H01 先教通用的「不重複／快速查找」概念，實作標記 🐍 Python |
| 映射／雜湊表 | 可用多份清單勉強模擬，不適合本階段 | 目前課程工具箱沒有鍵值對積木 | `dict` | H01 與 Judge-007「兩數之和」標記 🐍 Python 實作 |
| 多欄自訂排序 | 沒有可直接自訂鍵的排序積木 | 基本 `lists_sort` 無法表達本課的多欄鍵 | `tuple` 與 `sort(key=...)` | H04 的排序規則是通用概念，本課實作標記 🐍 Python |
| 型別轉換 | 沒有原生型別區分，數字與字串自動判斷 | 沒有原生型別區分，積木自動判斷 | `int()`／`str()` 需手動轉換 | 概念 5 明說 input() 一律回傳文字 |
| 小數格式化輸出 | 有四捨五入積木，沒有補 0 對齊位數的格式化 | 同 Scratch，沒有補 0 對齊位數的格式化 | `f"{x:.2f}"` | 概念 8 核心題與變體需要補 0 格式化，本課整關標記 🐍 Python |
| 錯誤訊息與不定行輸入 | 沒有 Traceback，執行期錯誤不會停下來報型別 | 積木層級擋掉多數型別錯誤，也沒有讀到 EOF 的積木 | `Traceback` 與 `sys.stdin` | M14 整關標記 🐍 Python；「先看錯誤類型再看行號」與三種測資設計則是通用能力 |

🐍 標記代表「目前此題的教材與自動判分實作使用 Python」，不代表該概念在其他程式語言中不存在。

## 九、獨立題庫規格原則

- 題號預留 `021`–`040`，正式落檔前仍須確認 ID 未被占用。
- 每題只有一個主要學習目標，題面先說任務再說情境。
- 輸入必須有限且有效；輸出必須唯一、精確、可用純文字比較。
- 正式 JSON 至少 8 組 `testCases`，包含公開範例、最小值、上限代表值、分支、重複／相等及常見錯誤殺手資料。
- 解法只能使用 Python 標準函式庫；不得使用網路、檔案、亂數或互動輸入提示。
- LV.2題預設 `M-7`／`M-8`，LV.3題預設 `M-9`／`M-HS`；難度標籤不能取代先備知識檢查。
- 題庫題與講義題同概念但不同任務結構。例如講義學「數母音」，出口題應要求處理另一種分類或回報位置，而不是只換字串。

## 十、通關與回退規則

| 狀態 | 判準 | 建議動作 |
|---|---|---|
| 可前進 | 核心題與 A 獨立通過；能說明一個邊界 | 進入下一關，B 可作回家練習 |
| 需鞏固 | 核心題可完成，但 A 仍需關鍵提示 | 重做追蹤表與 A 的不同測資 |
| 需回退 | 無法預測迴圈／狀態如何變化 | 回到對應先備關卡，不直接揭露答案 |
| 已遷移 | B 與出口題皆能完成，且能自訂測資 | 標記能力節點熟練 |
