## 閱讀順序

1. 先審閱「課程與題庫總綱」，確認程度與題量。
2. 再逐關審閱LV.2、LV.3講義；尤其確認情境、用語及先備知識。
3. 最後審閱 021–040 題庫規格，確認限制、輸出與演算法邊界。
4. 核准後才進入資料結構轉換、測資產生、參考解答與網頁整合。
