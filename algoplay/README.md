# 🎮 AlgoPlay 演算法遊樂場

演算法就是**用有限的資源，解決真實的問題**。AlgoPlay 先讓學生在生活問題裡體會「為什麼要學演算法」，再用動畫與遊戲看懂每一步，最後銜接《Hello 演算法》系統性地學習。

> 狀態：第一版（2026-09-22 建立，2026-09-23 把城鎮改寫成 2D 像素小鎮、關卡改成一個畫面的遊戲框，2026-09-24 首頁收成兩個選單）。完成小鎮 3 棟建築、「二分搜尋」模組，以及通往系統學習的銜接卡。

## 三階段學習路徑

| 階段 | 對象 | 學完能說出 | 形式 |
|---|---|---|---|
| ① 生活城鎮 | 國小、零基礎 | 「同一個問題，方法不同，花的資源差很多」 | 每關 5～10 分鐘，**不用寫程式** |
| ② 動畫與遊戲 | 國中以上、剛學程式 | 「這個演算法每一步在做什麼、為什麼」 | 👀 看 → 🤔 猜 → 🕹️ 做 → 🤖 教機器人 |
| ③ 系統學習 | 國中後段、高中、APCS | 「複雜度多少、怎麼實作、適合什麼題目」 | 讀《Hello 演算法》＋寫 ThinkLab 題目 |

越往後走，人數本來就會越少。國小學生停在第一或第二階段就很成功，不需要每個人都讀到第三階段。

三階段是課程的設計，不是畫面上的選單。**首頁只有兩個選單：演算法小鎮、會動的演算法**，一個畫面就看得完，不用捲動；第三階段的《Hello 演算法》與題目連結放在每個模組的「下一步」銜接卡裡，玩完才會遇到。

## 設計原則

- **先玩，再命名。** 城鎮的關卡名稱只寫生活問題，例如「終極密碼」。演算法的名字要破關後才揭曉，並收進「演算法圖鑑」。老師可以在首頁下方的「給老師」打開對照表。
- **限制逼出演算法。** 每一關都有看得見的資源計量條（次數、硬幣數、距離、時間）。像「1～100 萬限 20 次」這種限制本身就是提示，學生會自己想到「猜中間」。
- **小 AI 是被驗收的對象。** 每棟建築都有一個「小 AI」角色，提出聽起來合理、其實有問題的做法：一個一個猜、每次拿最大的、全部試一遍。學生要實際測試、比較、找反例。要傳達的是：AI 可以提出做法，但要判斷做法好不好，你得懂演算法。
- **參與程度決定學習成效。** Hundhausen 等人（2002）的整合分析和 Naps 等人的參與度分類都指出：只看動畫的效果有限，要讓學生預測、動手操作，才會真正理解。所以第二階段的每個模組都有「猜」和「做」。

## 第一版內容

### 首頁（`index.html`）

一個畫面、兩個選單，不用捲動：左邊是**演算法小鎮**，直接放小鎮的即時畫面；右邊是**會動的演算法**，放一段一直在跑的排序動畫（`core/preview.js`）。選單下面只寫進度（幾關、圖鑑收集到幾個），不寫說明；「給老師」的對照表和清除進度收在對話框裡，平常看不到。從主站首頁的「演算法遊樂場」按鈕進來。

### 選單一：演算法小鎮（`town/`）

一進到 [`town/index.html`](town/index.html) 就是一張 2D 俯視的像素小鎮夜景：街道、路燈、池塘、公園，七棟建築亮著燈。**整個小鎮就是一個畫面**：地圖是 3:2，寬度寫成 `min(100%, (100dvh - 118px) * 1.5)`，視窗矮的時候地圖跟著縮，不用捲動。操作以圖像為主：

- **點建築，角色就沿著街道走過去**（走法用廣度優先搜尋算最短路），走到門口鏡頭往前推進，關卡在同一頁展開，不換頁。關完按「← 回小鎮」鏡頭再拉回來。
- **還沒玩過的建築**門口會跳「!」，**破關的建築**會飄出星星；施工中的建築圍著鷹架和警示帶。
- **公園裡的佈告欄**就是演算法圖鑑，走過去點一下會打開。
- **小 AI 站在鎮口的路燈下**，你走近它會轉頭看你。它是貫穿三關的角色，關卡裡的對話框、便利商店的托盤、旅行社的灰線都是同一隻（`core/cast.js`）。
- 每棟建築都有名牌，可以用 Tab 選、Enter 進入；網址 `#guess`、`#coins`、`#trip` 可以直接連到某一關，瀏覽器的返回鍵會回到小鎮。

| 建築 | 生活問題 | 小 AI 的做法 | 為什麼要學演算法 | 偷偷學到 |
|---|---|---|---|---|
| 🎉 教室 | 終極密碼：1～100 限 7 次、1～100 萬限 20 次 | 從 1 開始一個一個猜 | 方法不同，花的資源差很多 | 二分搜尋、O(log n) |
| 🏪 便利商店 | 找零錢要用最少的硬幣；夜市代幣 1、3、4 點找 6 點 | 每次都拿最大的 | 直覺的方法不一定對，要能找出反例 | 貪婪演算法、動態規劃 |
| 🧳 旅行社 | 畢旅走完 5 個景點的最短路線；景點變多時要算多久 | 把所有順序都試一遍 | 電腦再快，也救不了太笨的方法 | 窮舉、組合爆炸、O(n!) |

每棟建築都有 4 個步驟（例如：自己玩 → 跟小 AI 比 → 挑戰變大 → 結算），最多可以拿 3 顆星。

**一關就是一個畫面。** 進關先看一張任務卡（說明都在這裡），按下開始才進到玩的畫面：整關固定一個視窗高，上面是頂條（回小鎮、進度圓點、星星），左邊是舞台，右邊是資源、小 AI 和紀錄，玩的過程不用捲動。結算是換一個畫面，不是往下接：說明方法的名字和「為什麼要學演算法」，出一題確認，並連到第二階段和《Hello 演算法》的對應章節。

終極密碼還多了幾樣：出題的老師是像素角色，會指上指下；每猜一次，被排除的數字會一格一格掃掉並飛出「排除了 50 個！」；剩下的次數畫成一排會熄滅的燈；第 2 關是**跟小 AI 同場比賽**（它從 1 開始一個一個爬，你用你的方法，看誰先猜中）；第二顆星要**完美二分**——每一次都猜在範圍正中間。

地圖上另有 4 棟施工中的建築：消防隊（BFS）、畢旅行李（背包 DP）、美術教室（連通區塊）、飲料店（佇列）。

### 選單二：會動的演算法（`modules/`）

`modules/index.html` 是這一區的入口，列出所有模組。**這一區才剛開始**，目前只有二分搜尋做完，基礎排序和 BFS 走迷宮還在製作中。二分搜尋模組有五個分頁：

| 分頁 | 學生做什麼 |
|---|---|
| 👀 看 | 播放／暫停／單步／拖曳時間軸，看 i、j、m 指標、Python 程式碼行高亮與變數面板。可以切換成線性搜尋比較次數，也可以輸入自己的數列（沒排序時會提示並幫忙排好）。 |
| 🤔 猜 | 動畫在關鍵步驟停下，先回答「中點是第幾格」「接下來往哪邊找」，答完才繼續，並統計一次答對的題數。 |
| 🕹️ 做 | 格子裡的數字先蓋住，要「打開」才看得到。學生自己點出中點、決定往左或往右，按錯會說明原因並記錄錯誤次數。 |
| 🤖 教機器人 | 用 Blockly 積木寫程式，教機器人玩終極密碼。系統會用 1～100 的每一個答案，以及 1～100 萬的 60 個抽樣答案測試，最多拿 3 顆星。可以重播任何一局，重播時積木會跟著高亮；旁邊也會即時顯示積木轉成的 Python。 |
| 📚 下一步 | 銜接卡：「你玩過的」對照「書上怎麼說」，附《Hello 演算法》章節連結、積木與書上 Python 的並排比較，以及 ThinkLab 題目 016、180、204。 |

程式碼面板的變數名稱（`nums`、`target`、`i`、`j`、`m`）和《Hello 演算法》相同，學生切換到書上時不會陌生。

## 開啟方式

在 ThinkLab 專案根目錄啟動任意靜態伺服器：

```sh
python3 -m http.server 8080
```

開啟 <http://localhost:8080/algoplay/>。請用 HTTP 網址：直接雙擊 `index.html` 的 `file://` 模式無法載入 JavaScript 模組。不需要 npm 安裝或建置步驟，可以直接隨主站部署到 GitHub Pages。

## 技術架構

```
algoplay/
├── index.html / home.css / home.js   首頁：兩個選單（各一張會動的預覽圖）、給老師的對照表
├── core/
│   ├── base.css       共用樣式（色彩、字體、按鈕、面板都沿用主站）
│   ├── catalog.js     建築、圖鑑、模組清單
│   ├── progress.js    進度（localStorage）
│   ├── player.js      步驟播放器與鍵盤快捷鍵
│   ├── python.js      Python 程式碼上色
│   ├── cast.js        像素角色：小 AI 與老師（畫在 canvas 上，可放大）
│   ├── preview.js     首頁「會動的演算法」的排序預覽動畫
│   └── ui.js          元素建立、計量條、燈號、小 AI 對話、選擇題
├── town/              演算法小鎮
│   ├── index.html     小鎮頁面（關卡在這裡展開，不換頁）
│   ├── world.js       地圖格子、建築位置、BFS 找路（純邏輯）
│   ├── sprites.js     像素美術：地面、建築、角色、燈光
│   ├── scene.js       遊戲迴圈、走路、鏡頭
│   ├── town.js        名牌、進出關卡、圖鑑
│   ├── level-ui.js    關卡的遊戲外框：任務卡、頂條、結算畫面
│   ├── logic.js       三關的純邏輯（可測試）
│   └── guess.js／coins.js／trip.js  三棟建築的關卡
├── modules/
│   ├── index.html / gallery.css / gallery.js   會動的演算法：模組列表
│   └── binary-search/
│       ├── algo.js        演算法（generator，每一步 yield 一個快照）
│       ├── app.js         看／猜／做／下一步
│       ├── robot-core.js  積木解譯器、評分、轉 Python（純邏輯）
│       └── robot.js       Blockly 工作區與重播（第一次打開分頁才載入）
└── test/              node 測試
```

- **小鎮是一張 384×256 的 canvas**，用 CSS 放大並保持像素感（`image-rendering: pixelated`），所有圖都用方塊畫出來，沒有圖檔。建築名牌是 HTML 按鈕，位置用百分比，所以縮放時不會跑掉，中文也不會糊掉，還能用鍵盤操作。
- **關卡是元件，不是頁面。** `startGuess(root, { onExit, onProgress })` 會把整關畫進指定的容器，小鎮頁再把它放進全螢幕的面板。
- **關卡的框由 `gameShell()` 提供**：`setStep` 換進度圓點、`setStars` 換頂條星星、`briefing()` 是進場任務卡（回傳 Promise）、`flash()` 是舞台中央的大字（比賽倒數）、`finish()` 把玩的畫面換成結算畫面。框是 `100dvh` 的格線版面，所以關卡只要把內容塞進舞台，不必自己算高度。
- **像素角色只有一份。** `core/cast.js` 的 `drawAI`／`drawTeacher` 同時畫在小鎮的畫布上和關卡的頭像裡（`pixelAvatar()` 包成會自己停止的 canvas 元素），換心情只是換表情，不會重畫整隻。
- **演算法和畫面分開。** 演算法寫成 generator，播放前先把所有步驟收集成陣列，所以上一步只是換一個索引。「看」依序播放，「猜」在標有 `ask` 的步驟停下來出題。
- **教機器人不使用 `eval`。** `robot-core.js` 直接解譯 Blockly 的 JSON 存檔，只認得工具箱裡的積木。每局最多執行 10 萬步，1～100 最多猜 200 次、1～100 萬最多猜 1,000 次，所以無窮迴圈也會停下來，並指出是哪一塊積木出了問題。猜的每一次都記錄當時的變數，拿來重播。
- **Blockly 沿用主站的 `assets/vendor/blockly`（12.3.1）**，套用深色主題。只在 AlgoPlay 裡把「賦值 %1 成 %2」等較難懂的標籤改成「設定 %1 為 %2」，不影響主站的編輯器。
- **進度只存在學生自己的瀏覽器**：`thinklab_algoplay_v1`（星星、圖鑑、模組進度）和 `thinklab_algoplay_robot_v1`（機器人的積木）。讀不到或存不進去時照常運作，只是不保留進度。共用電腦可以在首頁「給老師」清除進度。

## 視覺與無障礙規範

- **視覺風格維持與主站相同**：深色底 `#0c0d12`、重點色 `#3b82f6`、Plus Jakarta Sans／Noto Sans TC／Fira Code、細框線面板。頁首沿用流程圖實驗室的樣式，首頁沿用主站的格線背景與光暈。新增元件時請從 `core/base.css` 的變數取色。
- **關閉 Fira Code 的連字**：學生要看到真正要打的 `<=`、`==`，而不是 `≤`、`═`。
- **不只靠顏色**：排除的格子加上刪除線、找到的格子加上 ✓，星星也有文字說明。
- **鍵盤操作**：空白鍵播放／暫停，← → 單步；分頁可用左右鍵切換；地圖上的景點可以用 Tab 選取。
- 支援手機寬度（390px 不會出現橫向捲軸），並遵守「減少動態效果」的系統設定。

## 測試

```sh
node --test algoplay/test/*.test.mjs
```

測試內容包括：小鎮地圖的每個門口都走得到、BFS 找出來的是最短路、建築不重疊；二分搜尋和線性搜尋與 `indexOf` 的結果一致，而且比較次數不超過 ⌈log₂(n+1)⌉；找零錢在台幣下「每次拿最大」一定最少，在夜市代幣下會出錯；畢旅地圖的最短路線唯一，而且「每次去最近的」找不到它。教機器人的部分，參考解法能拿滿 3 顆星，小 AI 的程式在 1～100 萬會失敗；錯誤訊息、無窮迴圈上限，以及積木轉成的 Python 也都有測試。

- **ThinkLab 主站**：AlgoPlay 放在 `algoplay/` 裡，比照流程圖實驗室（`../test/`）的做法，沒有動到編輯器或題庫。主站首頁的入口按鈕和導覽列都叫「演算法遊樂場」。
