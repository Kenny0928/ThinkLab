QUICK GUIDE
把邏輯，一步一步看懂
01 建立與連線
拖曳或點選左側節點。在節點的出口按下並拉到下一個入口；也可以依序點選兩個連接點。判斷節點的 True 與 False 都需要接好。
02 編輯內容
點選節點，在「節點設定」輸入變數或運算式。每個處理節點只執行一個指定，例如 sum = sum + i。
03 執行與回看
提供每行一筆的測試資料，或留空等待互動輸入。播放時可暫停、回退或拖曳時間軸；上一步會同步還原變數與輸出。
暫停控制畫面播放，背景計算仍可能繼續。停止會中止計算並保留已產生的紀錄。修改程式或測試資料會清除舊軌跡；移動節點與縮放則保留。
支援的運算
+ − * / // %、括號、比較 > < >= <= == !=、布林 True False and or not。/ 是除法，// 是向下取整除法，% 餘數與除數同號。
數字與文字不能直接相加；判斷條件必須是布林值。輸出節點每次輸出一行。變數使用英文字母、數字或底線，且不能以數字開頭。
