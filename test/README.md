# ThinkLab 流程圖實驗室

依照 [原始需求規格](./視覺化流程圖程式執行器需求規格.md) 製作的獨立第一版。所有新增檔案都在 `test/`，暫時不變更主站導覽、編輯器、題庫或評分流程。介面沿用主站的深色背景、藍色重點色、細框線與字體風格，沒有額外 CDN 載入依賴。

## 開啟方式

在專案根目錄啟動任意靜態 HTTP 伺服器：

```sh
python3 -m http.server 8080
```

接著開啟 <http://localhost:8080/test/>。請使用 HTTP 網址；直接雙擊 `index.html` 的 `file://` 模式無法可靠載入 JavaScript 模組與 Web Worker。不需要 npm 安裝、後端 API 或建置步驟。

## 使用流程

1. 每次開啟或重新整理都從空白畫布開始，不會自動載入範例或還原草稿。可直接加入節點、手動載入範例，或匯入 JSON 作品。
2. 從節點工具列新增開始、結束、輸入、輸出、處理及判斷節點。
3. 從輸出接點拖曳到目標的輸入接點；判斷節點分別連接 True 與 False。
4. 選取節點並編輯屬性，再執行驗證。
5. 在測試輸入區每行放一筆資料後執行，或等流程執行到輸入節點時再回答。
6. 利用暫停、上一步、下一步、時間軸及播放速度，觀察節點、變數、條件與輸出。
7. 要留待下次繼續的作品，請先匯出 JSON；下次開啟後再手動匯入。

每個節點執行完畢算一步；面板顯示該步執行後的狀態，並呈現變數前後差異。回退只讀取已記錄的軌跡，變數、輸入紀錄及輸出都會同步回復。

### 連線方向與迴圈

連線採用帶圓角的水平／垂直路徑，依節點位置選擇接點，並避開其他節點。左右並排時會優先接到近側，不再強制從下方繞到上方。判斷節點的 True／False 標籤會隨連接目標選擇左右出口；標籤和原本的分支意義始終一致。

最初進入判斷的路徑使用上方入口，迴圈回線使用下方入口，讓「第一次進入」與「重複判斷」容易區分。移動節點時也會更新受到遮擋的其他連線。上述方向與路徑皆由畫布推算，不改變節點位置、既有 JSON、程式邏輯或執行軌跡；舊作品重新載入後會自動使用新繞線規則。

若把節點重疊到完全沒有可用通道，畫布仍會保留連線；把節點移開即可恢復自動繞線。交錯程度很高的複雜圖仍可能出現線與線交叉。

## 第一版語意

這是採用 Python 風格的受限教學語言，不是完整 Python 執行環境。

| 功能 | 規則與例子 |
| --- | --- |
| 處理節點 | 一個節點只寫一個指定敘述，例如 `sum = sum + i`。第一次指定即建立變數。 |
| 變數名稱 | 使用英文字母、數字與底線，第一個字元不能是數字；不可使用語言保留字。 |
| 值 | 有限數字、文字與布林值 `True`／`False`；數字採 JavaScript 的雙精度浮點數，並非 Python 的任意精度整數。 |
| 運算 | 支援 `+`、`-`、`*`、`/`、`//`、`%`、括號及正負號；`//` 向下取整，餘數方向與除數一致。 |
| 比較 | 支援 `==`、`!=`、`<`、`<=`、`>`、`>=`。 |
| 邏輯 | 支援 `and`、`or`、`not`；運算元必須是布林值，`and`、`or` 會短路。 |
| 文字 | 使用單引號或雙引號，例如 `name + "，你好！"`；不會將數字自動轉成文字。 |
| 輸入 | 節點明確指定整數、數字、文字或布林型別；整數必須在安全整數範圍內，布林值須填 `True` 或 `False`。無法轉換的輸入會顯示錯誤。 |
| 輸出 | 一個運算式，每次輸出自動換行。 |
| 判斷 | 運算結果必須是布林值。 |
| 迴圈 | 使用連線回到前面的節點；可以有多條路徑匯入同一個節點。 |

不支援函式呼叫、物件屬性、陣列、原生 JavaScript 或任意 Python 程式。禁止直接執行使用者文字；運算式由 Parser 轉為 AST，再交由受限解譯器處理。

## 軌跡與輸入

- 計算與動畫各自運作。Worker 產生軌跡，播放器依速度顯示；暫停播放不會改變計算結果。
- 遇到尚未提供的輸入時，計算會等待。回答後才產生後續軌跡，等待期間的總步數尚未確定。
- 回放既有輸入沿用當時的答案，不會重複索取。修改測試輸入會使舊軌跡失效，再次執行時重新計算。
- 展開輸入紀錄可修改某一筆答案。系統以該筆以前的答案與新值重新計算，丟棄後續輸入並重新詢問；不會沿用已失效的軌跡。文字輸入允許空字串，預先測試資料每行一筆，最後一個換行只當作行尾。
- 輸入型別不正確時會保留等待狀態，允許修正，不會產生失敗的輸入步驟。
- 修改運算式、節點種類或連線會使舊軌跡失效。移動節點、平移及縮放只改變畫面，保留既有軌跡。
- 停止會終止 Worker，保留已產生的軌跡供檢查；重新開始會用目前作品與測試資料重新執行。
- 每次執行有獨立識別碼，過期 Worker 訊息不會套用到新版作品。

## 驗證與資源限制

執行前檢查開始及結束節點、必要連線、分支、合法連線、運算式及變數使用。無法到達的節點及只在部分路徑定義的變數提供警告；確定的結構或語法錯誤阻止執行。執行時仍檢查實際的未定義變數、型別及除以零等錯誤，並標示相關節點。

預設上限為 500 個節點、10,000 個執行步驟、64 KiB 輸出、8 MiB 軌跡及 3 秒計算時間。等待使用者輸入不計入計算時間。這些限制用來保護教學頁面的反應速度；觸發限制時會顯示可理解的錯誤。Worker 負責隔離與中止，受限語言負責限制可執行的操作。

另外限制每個字串 8,192 字、每個運算式 4,096 字、128 個變數及 2 MB 匯入檔案。數字採有限雙精度值，整數輸入須在安全整數範圍；小數計算可能有一般浮點誤差。主頁另有 Worker 無回應的保護計時器。觸發錯誤會停止自動播放，保留紀錄與「查看出錯位置」入口。

儲存格式有版本欄位，包含節點、連線、節點設定及畫布位置，不保存播放器狀態或驗證標記。瀏覽器草稿只存在目前網站來源與瀏覽器；重要作品請另外匯出 JSON 備份。

草稿使用獨立鍵值 `skilllab_flowlab_draft_v1`；替換作品前會盡力保留上一份作品於 `skilllab_flowlab_recovery_v1`；開啟時不讀取或覆寫既有草稿，開始編輯後才保存目前作品。這些備援不取代 JSON 匯出，亦不觸及主站既有草稿或通關紀錄。

## 檔案與整合界面

| 檔案 | 職責 |
| --- | --- |
| `index.html`、`flow-lab.css` | 獨立入口、主站視覺樣式、桌面三欄及窄螢幕堆疊 |
| `flow-app.mjs` | 作品保存、屬性面板、Worker 協定、軌跡播放器及觀察面板 |
| `flow-canvas.mjs` | 純 SVG 編輯器；拖曳、拉線、框選、多選、複製貼上、復原重做、縮放平移 |
| `flow-routing.mjs` | 接點方向、迴圈回線辨識、圓角直角連線及節點避障；只推算顯示幾何 |
| `flow-core.mjs` | JSON 格式檢查、Parser／AST、圖驗證、確定性受限解譯器 |
| `flow-worker.js` | 每批最多 100 個事件的分段執行、等待輸入與計算資源保護 |
| `examples.mjs` | 問候、奇偶、及格、較大值、累加、計數與無限迴圈七個範例 |
| `core.test.mjs`、`verify-browser.mjs` | 核心與真實瀏覽器整合驗證 |
| `routing.test.mjs`、`verify-routing.mjs` | 連線幾何、原附圖／鏡像布局、近距離接點及真實 SVG 碰撞回歸驗證 |

核心與畫布均為 ES modules，不依賴頁面的 DOM 結構或特定前端框架。`createExecution(graph).step()` 逐步產生不可變事件；等待時回傳 `waiting`，下一次 `step(rawInput)` 提供答案。Worker 以 `runId` 標記 `events`、`waiting`、`input-error`、`done` 訊息；主頁只接受目前執行的訊息。播放器以事件數量作為游標，變更速度不重新執行。

畫布拖曳只修改節點 transform、連線 path 與必要的接點；放開後才記錄整份作品。重新繞線也涵蓋被移動節點擋住的其他連線，保留既有 SVG 節點與選取／執行狀態。播放只更新節點／連線的狀態 class。時間軸列表僅建立游標附近最多 65 列；作品、引擎與播放狀態各自保存。

## 驗證方式

Parser、驗證器、解譯器及範例測試只需要 Node.js：

```sh
node --test test/core.test.mjs test/routing.test.mjs
```

瀏覽器整合驗證使用真實 Chrome／Chromium、真實 Worker 及獨立瀏覽器儲存空間，不會操作日常瀏覽器的草稿。先啟動靜態伺服器，再執行：

```sh
npm install --prefix /tmp/flowlab-browser-qa --no-audit --no-fund playwright-core
FLOWLAB_PLAYWRIGHT=/tmp/flowlab-browser-qa/node_modules/playwright-core/index.mjs \
  node test/verify-browser.mjs http://127.0.0.1:8080/test/
FLOWLAB_PLAYWRIGHT=/tmp/flowlab-browser-qa/node_modules/playwright-core/index.mjs \
  node test/verify-routing.mjs http://127.0.0.1:8080/test/
```

此安裝只供開發驗證使用，不是頁面執行依賴。驗證程式會自動尋找常見 Chrome／Chromium 路徑，也可用 `FLOWLAB_CHROME` 指定瀏覽器執行檔；用 `FLOWLAB_ARTIFACTS` 指定截圖及測試產物目錄，預設放在系統暫存資料夾。

2026-09-12 驗證結果：22 項核心測試、21 項真實 Chrome 瀏覽器情境全數通過，瀏覽器沒有持續性錯誤。包含 200 節點圖的執行、實際拖曳、縮放、保持 SVG 元素不重建，以及 1512×982 與 1024×768 桌面配置。主專案既有 41 題題庫驗證與 9 項編輯器驗證也全數通過；既有 Blockly 棄用提示仍存在。本專案無建置／型別檢查流程，新增 JavaScript 已做語法檢查。這些功能驗證不代表所有裝置均保證 60 FPS。

2026-09-13 連線優化：核心加上幾何測試共 27 項通過；新增 6 組真實 Chrome 繞線檢查，包含附圖布局、鏡像、獨立入口、無關障礙移動與 8～24 px 緊密間距。200 節點拖曳時重新繞線的本機量測中位數約 3.1 ms、95 百分位約 3.9 ms；此為測試機的幾何更新耗時，不是所有裝置的 FPS 保證。

## 後續整併

目前是桌面優先的獨立流程圖練習環境，未接入主站的題目作答及評分。後續可將畫布、執行引擎與播放器模組移入正式 `assets/`，保留版本化 JSON 格式，再新增主站入口及題目模板。陣列、函式、教師鎖定節點、流程圖轉 Python 與多人協作仍屬後續範圍。
